# assets フォルダ

ここに画像（WebP）を置くと、アプリが自動で表示します。

## 置き方

- ファイル名は、リポジトリ直下の `MuseForest/assets-list.txt` にある名前と**完全に同じ**にしてください（206件）。
- このフォルダ（`assets/`）の直下に置いてください。サブフォルダは不要です。

## ファイル名の規則

| 種類 | 形式 | 例 |
| --- | --- | --- |
| 背景（ナチュラルな森テーマ） | `bg-{場所}.webp` | `bg-living.webp` |
| 背景（その他のテーマ） | `bg-{テーマ}-{場所}.webp` | `bg-flower-garden.webp`、`bg-frost-treehouse.webp` |
| ミューズのコーデ | `muse-original.webp`（オリジナルの姿）／`muse-orig-{コーデ}.webp` | `muse-orig-pajama.webp` |
| 住人のポートレート | `villager-{住人}.webp` | `villager-ponta.webp` |
| 住人の表情・ゲーム用バリエーション | `villager-{住人}-{表情}.webp`（happy / think / surprised / sleepy / janken） | `villager-usami-happy.webp` |

## 画像がない場合

画像が1枚もなくてもアプリは動きます。表示されるはずの場所には、場面やコーデの名前を書いた
プレースホルダーパネルが出ます。一部の画像だけ置くこともできます（置いた分だけ実画像になります）。
