# ミューズの森（Streamlit版）

Muse のスペース「ミューズの森」を、Python + Streamlit で動くアプリに変換したものです。
あつまれ どうぶつの森のような世界で、Muse と一緒に暮らす小さなコンパニオンアプリです。
場所・テーマ・コーデ・お土産・住人・セリフ・ゲームのルールは、元のスペース（TypeScript）のカタログとロジックをそのまま持ち運んでいます。

## 動かし方

```bash
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで表示されるアドレス（通常 http://localhost:8501）を開くと遊べます。

## 遊び方

- **お部屋**： 場所（11か所）とテーマ（11種）を切り替えて、ミューズを「なでる」「話しかける」「着替える」。なかよし度が上がると ごほうびテーマが解放され、日付が来ると新しいテーマやコーデが届きます。お風呂・ダイニング・玄関では専用の過ごし方もできます。「お出かけ」では旅先のお土産を持って帰ってきます。
- **お友達**： 森の住人11人と会話したり、じゃんけん・数当て・クイズ・しりとりで遊べます。お友達ポイントが貯まると新しい住人が引っ越してきます。
- **ミッションとお店**： 毎日の小さな習慣ミッション（3つ/日）でミューズマイルを貯めて、家具と交換できます。交換した家具は各部屋に飾れます。
- **ミニゲームと図鑑**： 魚釣りと虫取りで、魚6種・虫6種の図鑑を集めます。
- **コレクション**： お土産31種のコレクション状況が見られます。
- **思い出ノート**： ミューズとの出来事が記録されます。

## 状態の保存

進行状況（なかよし度・マイル・お友達ポイント・着替え・飾った家具・お土産・図鑑など）は、
`app.py` と同じフォルダの **state.json** に自動保存されます。再起動しても続きから遊べます。
最初からやり直したいときは、アプリを止めて state.json を削除してください。

## 画像について

背景・ミューズの姿・住人のポートレートなどの画像（WebP、206枚）は、`assets/` に登録されています
（2026-11-23に全件アップロード完了。経緯は下の「開発の記録」を参照）。

- 画像ファイルが無い場合は、代わりに場面やコーデの名前を表示するプレースホルダーパネルが出ます。
- 画像の一覧は `assets-list.txt` にあります（詳しくは `assets/README.md`）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `app.py` | アプリ本体（カタログ・セリフ・ゲームロジック・画面をすべて含む単一ファイル） |
| `requirements.txt` | 依存パッケージ（streamlit、Pillow） |
| `assets-list.txt` | 対応する画像ファイル名の一覧（206件） |
| `assets/` | 画像を置くフォルダ（プレースホルダーの説明付き） |
| `state.json` | 進行状況の保存ファイル（初回起動時に自動生成） |
